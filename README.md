# Book de Marca — Personal Organizer

Book de padrões navegável: paleta 60-30-10, hierarquia tipográfica, tom de voz,
persona primária (Maria Júlia) e as cinco etapas do método.

Estrutura de layout herdada do site da Click.Jr (sticky stack + reveals + Lenis);
conteúdo e estilos vêm de `nexxus/organizer/` (`identidade-marca.md`,
`proto-persona.md`, `manual-operacional.md` e `book.pdf`).

```bash
npm install
npm run dev      # Vite + HMR
npm run build
npm run preview
npm run lint
node scripts/contraste.mjs   # checa os pares fundo/texto dos temas em WCAG AA
```

Sem seção de globo, de equipe, de contato ou de orçamento: é um book, não uma
landing de captação.
